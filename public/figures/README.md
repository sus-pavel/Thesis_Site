# Рисунки

Используйте:

- SVG — основной формат схем и графиков на сайте;
- PNG/WebP — только для растровых материалов или резервной копии;
- PNG для печати — не менее 300 dpi.

Общие требования:

- `viewBox` обязателен для SVG;
- текст должен оставаться читаемым на ширине 360 px;
- фон — прозрачный либо явно согласованный с сайтом;
- внутри SVG не должно быть внешних шрифтов, скриптов и ссылок;
- имя файла — латиница, `snake_case`;
- демонстрационный рисунок содержит видимую подпись «Демонстрационная схема».

Каждая подпапка содержит собственный README с ожидаемыми именами.
