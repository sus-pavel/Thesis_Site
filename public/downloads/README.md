# Файлы для загрузки

Положите сюда финальные утверждённые документы:

- `dissertation.pdf`;
- `autoreferat.pdf`;
- `presentation.pdf`;
- `brochure.pdf`.

До появления файлов карточки на странице `/downloads` остаются неактивными. После добавления PDF замените `button disabled` в `src/pages/downloads.astro` на ссылку вида `<a href="/downloads/dissertation.pdf" download>`.
