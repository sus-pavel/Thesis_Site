# Файлы для загрузки

Положите сюда финальные утверждённые документы:

- `dissertation.pdf`;
- `autoreferat.pdf`;
- `presentation.pdf`;
- `brochure.pdf`.

До появления файлов карточки на странице `/downloads` остаются неактивными. После добавления PDF карточка автоматически станет ссылкой при следующем `npm run dev` или `npm run build`; редактировать Astro-код не требуется.
