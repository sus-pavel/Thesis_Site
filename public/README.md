# Публичные файлы

Содержимое этой папки копируется Astro в корень готового сайта без преобразования.

- `data/` — машиночитаемые результаты и примеры;
- `figures/` — SVG/PNG/WebP для сайта и публикаций;
- `downloads/` — только утверждённые документы для скачивания.

Не храните здесь исходные ноутбуки, секреты, персональные данные и промежуточные тяжёлые выгрузки.
