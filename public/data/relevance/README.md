# Актуальность и контекст

- `energy_growth.csv`: `year`, `region`, `electricity_twh`, `source`, `is_placeholder`;
- `diesel_sites.geojson`: `FeatureCollection`, геометрия `Point`, свойства `site_id`, `name`, `region`, `installed_capacity_mw`, `fuel`, `source`, `is_placeholder`.

Координаты GeoJSON задаются в WGS84: `[longitude, latitude]`. Демонстрационные точки не должны выглядеть как фактический реестр объектов.
