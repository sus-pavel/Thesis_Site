# Профили нагрузки

Основной файл: `placeholder_load_profile.csv` (замените содержимое или добавьте новый файл и обновите путь в `src/data/visuals.ts`).

| Поле | Тип | Обязательно | Описание |
|---|---|---:|---|
| `timestamp` | ISO 8601 | да | момент измерения с часовым поясом |
| `feeder_id` | string | да | стабильный идентификатор фидера |
| `p_kw` | number | да | активная мощность, кВт |
| `q_kvar` | number | нет | реактивная мощность, квар |
| `quality_flag` | string | нет | `ok`, `interpolated`, `missing` |
| `is_placeholder` | boolean | рекомендуется | признак демонстрационной строки |

Шаг времени должен быть постоянным внутри одного ряда. Не смешивайте кВт и МВт.
