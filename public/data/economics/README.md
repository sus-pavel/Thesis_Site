- `opex_comparison.csv`: `scenario`, `opex_rub_per_day`;

Храните исходные результаты сценариев отдельно от параметров финансовой модели. Рядом можно добавить `metadata.json` с полями `currency`, `price_base_year`, `discount_rate`, `horizon_years`, `capex_included`, `is_placeholder`.
