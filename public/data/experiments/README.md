# Эксперименты и устойчивость

Сюда помещаются таблицы, из которых построены рисунки `public/figures/experiments`.

Рекомендуемый длинный формат:

`experiment_id`, `variant`, `metric`, `value`, `unit`, `sample_id`, `seed`, `is_placeholder`.

Для теста окна SSA используйте поля `window_length`, `ari`, `nmi`, `correlation`, `cumulative_contribution`. Параметры эксперимента и версии кода фиксируйте в `metadata.json`.
