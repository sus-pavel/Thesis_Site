# Классификация нагрузок

- `load_classes.csv` — справочник классов и ключевых ограничений.
- `dr_actions.csv` — допустимые управляющие воздействия по классам.
- `optimization_parameters.csv` — численные параметры, границы и штрафы оптимизационной модели.

Термины `class_id` не следует менять после подключения визуализаций.
