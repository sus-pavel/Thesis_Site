# Данные сайта

Каждая подпапка соответствует одному этапу исследования и содержит собственный `README.md` со схемой полей.

Общие правила:

- кодировка UTF-8 без BOM;
- CSV-разделитель — запятая;
- десятичный разделитель — точка;
- время — ISO 8601 (`2024-04-01T00:00:00+03:00`);
- мощности: суффиксы `_kw` или `_mw`;
- доли: `0…1`, проценты: `0…100`;
- идентификаторы (`feeder_id`, `component_id`, `class_id`) стабильны между файлами;
- демонстрационные строки помечаются `is_placeholder=true` или явно описываются как примеры в README.

Не заменяйте исходные численные результаты значениями, восстановленными из изображений. Загружайте экспорт непосредственно из Python/Jupyter.

| Папка | Назначение |
|---|---|
| `relevance/` | контекст и актуальность |
| `load_profiles/` | исходные временные ряды |
| `ssa/` | SSA-компоненты, признаки и кластеры |
| `drpi/` | DR PI, тепловые карты и чувствительность |
| `load_classification/` | классы нагрузок и DR-действия |
| `simulation/` | сценарии Base/DSM/BESS |
| `economics/` | OPEX, NPV, IRR, PI |
| `emissions/` | Scope 1 и коэффициенты |
| `experiments/` | проверки устойчивости |
| `publications/` | библиографические записи |
